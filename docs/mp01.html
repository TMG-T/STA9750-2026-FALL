Watching the Watchers: Exploring Netflix Viewership Data

Context

Since 2023 Netflix has been been releasing a What We Watched, referred to WWW going forward, report semi-annually. This report contains data on titles available on Netflix, how many views they got, how many hours watched, if they were a live event, if it was available globally, time of observation, when the title was released, and a title’s runtime.

I aim to explore this data, and to advise on whether production should be focused on TV shows or on Movies, if the performance of live events warrants continued production, and what titles should be acquired for Netflix’s catalog

Getting the data

This data was queried from Netflix’s corporate relations website. With cleaning being done to adjust column names for tidy-ness, and data types to make them more appropriate for analysis, such as converting “year” to numeric data type, and “avalible_globally” to logical type.

Data Acquision with R 
#' Acquire Netflix What We Watched Reports
#' 
#' This function will acquire and standardize all data for MP#01
#' from Netflix. Because Netflix hosts the data files behind a CDN, we
#' are accessing the release pages and automatically extracting links to the
#' relevant files (with CDN hash). 
#' 
#' After import, files are stacked vertically and some basic cleaning is
#' performed. 
load_netflix_data <- function(){
  # Note to students: Make sure you have installed the tidyverse and fs packages
  #                   before beginning this assignment. If you aren't sure,
  #                   simply run `library(tidyverse)` at your R Console and, if
  #                   you don't see an error message, `tidyverse` has been 
  #                   installed. (Same for `fs`) If you still need to install
  #                   either package, use the `install.packages` function as 
  #                   demonstrated in class.
  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
  
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
    
    return(local)
  }
  
  NETFLIX_URLS |> 
    map(read_html) |> 
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |> 
    map_chr(html_attr, "href") |> 
    enframe("period", "url") |> 
    mutate(path = path(data_dir, paste0(period, ".xlsx")), 
           path = map2(url, path, download_if_needed), 
           data = map(path, read_excel, skip=3, na="*"), 
           data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |> 
    select(-url, -path) |> 
    mutate(year=str_sub(period, 1, 4), 
           half=str_sub(period, start=6), 
           period_start = make_date(year, if_else(half==1, 1, 7), 1), 
           period_end = make_date(year, if_else(half==1, 7, 12), if_else(half==1, 30, 31))) |> 
    filter(!is.na(`Hours Viewed`)) |> 
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"), 
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)), 
           .by=Title, 
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"), 
           Title = str_remove(Title, "[^[:ascii:]].*"), 
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year, 
           period, 
           period_start, 
           period_end, 
           Title, 
           -half, 
           Runtime, 
           Views, 
           `Hours Viewed`, 
           `Release Date`,
           `Available Globally?`, 
           live_event) |>
    rename(title = Title, 
           runtime  = Runtime, 
           views  = Views,
           hours_viewed  = `Hours Viewed`,
           release_date  = `Release Date`,
           available_globally  = `Available Globally?`) |>
    mutate(
      year = as.integer(year), 
      available_globally = available_globally == "Yes"
    ) # Recall that double equals (==) checks for equality

}

NETFLIX_DATA <- load_netflix_data()

total_hours <- NETFLIX_DATA |>
  summarise(Total_Hours = sum(hours_viewed, na.rm = TRUE), .by = period)

shows_nd <- NETFLIX_DATA |>
  filter(str_detect(title, "Season") | str_detect(title, "Series") | str_detect(title, "Volume") | str_detect(title, "Periode") | str_detect(title, "Part") | str_detect(title, "Arc")) |>
  filter(runtime >= 180) |>
  summarise(show_hours = sum(hours_viewed, na.rm = TRUE), .by = period)

movies_nd <- NETFLIX_DATA |>
  filter(!str_detect(title, "Season")) |>
  filter(runtime >= 0 | runtime <= 360) |>
  summarise(movie_hours = sum(hours_viewed, na.rm = TRUE), .by = period)

total_hours |>
  left_join(shows_nd,  by = "period") |>
  left_join(movies_nd, by = "period") |>
  mutate(
    time_fraction_shows  = show_hours  / Total_Hours * 100,
    time_fraction_movies = movie_hours / Total_Hours * 100
  ) |>
  select(period, time_fraction_movies, time_fraction_shows) |>

  fmt_number(columns = starts_with("time_fraction"), decimals = 1) |>

Platform Strategy Memo

Given the findings from the data the two clear strategies that Netflix can employ going forward are increasing production and release of TV shows, and acquire more household name TV shows for Netflix’s catalog.

This is due to shows continually outperforming movies period after period, with shows making up at a minimum 60% of hours spent viewing content on Netflix. Moreover, in each period these observations were made, the titles that garnered the highest number of hours viewed were all TV shows.

While this may be influenced by the fact that shows simply have a higher runtime than a given movie. I would argue the re-watch-ability of a given TV show, particularly top performers, is the biggest driver of this trend as more watches of this already high runtime subset of titles will drive high numbers of hours viewed.

In addition to this the titles with the consistently highest performance are all shows that are house hold names, such as Breaking Bad, Bridgerton, Squid Games, Stranger Things etc.

This signals that these types of shows accumulate high viewership through repeated watching over the period that this data was captured. Subsequently, in acquiring more house hold titles Netflix would be able to boost the number of hours spent viewing content on Netflix consistently through repeated watches from users.

This is advantageous for Netflix as keeping users on its platform will allow them to show more ads to their ad supported subscription tier increasing ad revenue, allow Netflix more hours to collect user data, and to keep users away from going on other streaming platforms to harden Netflix’s competitive edge over platforms like Disney, HBO, or Paramount.

However there are limitations to these strategies. As they rely entirely on viewership data and ignore outside context such as economic, cultural, or company-wide information that may hinder the effectiveness of these strategies. Given access to more data these recommendations could be more complete and accurate to the full picture of Netflix’s current standing.
